> 版本:1.0(2026-08-05)

## 1. 产品概述

一款通过**阅读例句**学习英语单词的 App。与传统背单词软件的核心差异:每个单词配 **9 句例句,分 3 个难度层次(L1/L2/L3 各 3 句)**,层次在句式、用法、长度上逐层递进;内容由 AI(DeepSeek 等 OpenAI 兼容 API)生成并本地缓存,辅以开源词典数据(ECDICT)与用户自导入词典(MDX)。

- **平台**:Android + Web 优先,预留 iOS
- **形态**:本地优先(数据存设备),无云服务
- **目标用户**:英语学习者,按考试等级(高考/四六级/专四专八)自选水平

### 1.1 核心差异化

"每词固定句数 + 按难度分层、层间难度递进"的显式设计在开源生态中无成型先例(调研结论),差异化押注在**分层设计与例句质量**上。

## 2. 用户流程(端到端)

```
首次启动:选择英语水平(高考/四六级/专四专八)
  → 设置每日阅读量 X、预算倍数 M、并发数(可默认)
  → 创建词集(单词本)
  → 导入单词表(txt/markdown/excel/csv/MDX)
  → 预览确认 → 入库(词集去重)
  → [MDX] 导入完成页:筛选入口 / "开始生成"入口
  → 学习:打开单词 → 3 视图模式之一
  → 点开未生成词 → 即时生成(最高优先级)
  → 后台预生成按预算自动补货(M×X)
  → 标记 认识/不认识 → 进入轻量复习(1/3/7 天)
  → [多设备] 局域网自动同步个人层 / 手动拉取词集
```

## 3. 核心概念(术语表)

| 术语 | 定义 |
|---|---|
| **词集 (WordSet)** | 用户创建的学习单位 = 一批要学的单词清单。数据模型的中心,无独立"素材库"层 |
| **词 (Word)** | 词集内条目;素材(音标/释义/例句)按词挂载 |
| **素材** | 词的音标、释义、例句、短语、音频;来源 = ECDICT / MDX / AI |
| **内容层** | 词集、素材、AI 生成物。可导入导出、可局域网拉取 |
| **个人层** | 复习状态(认识/不认识、间隔、每日进度)。自动同步,不随词集导出 |
| **生成状态** | 未生成 / 排队中 / 生成中 / 已完成 / 失败 |
| **每日阅读量 X** | 用户设置的每日学习词数 |
| **预算倍数 M** | 默认 3,可配置;后台预生成上限 = M×X |
| **批次 (Batch)** | 后台预生成任务的一个执行单元,长度由预算决定 |
| **视图模式** | 学习/查阅/复习 三种单词页形态 |
| **展示配置** | 例句区 中英/仅英/仅中 的显示切换 |

## 4. 内容契约:AI 生成规格

> 门票:[讨论:AI 生成内容契约](#6)

### 4.1 每词产出 schema

```json
{
  "word": "run",
  "phonetic": { "uk": "/rʌn/", "us": "/rʌn/" },
  "senses": [
    {
      "pos": "v.",
      "meaning": "to move using your legs, going faster than walking",
      "examples": [
        { "level": 1, "en": "I run every morning.", "zh": "我每天早上跑步。" }
      ]
    }
  ],
  "phrases": [
    { "phrase": "run out of", "en": "We ran out of milk.", "zh": "我们的牛奶喝完了。" }
  ],
  "unclassified_examples": []
}
```

### 4.2 硬性约束

- **9 句恒定**:L1×3 + L2×3 + L3×3,按 `level` 字段**全局校验**(不按 sense 校验),校验规则:每 level 恰 3 句
- **按义项分布**:9 句按义项重要性分配存放(3 个义项 → 4/3/2);至少 7 句必须挂在具体 sense 下,最多 2 句进 `unclassified_examples`(习语化用法)
- **释义→例句强挂钩**:例句语义上属于该义项
- **短语**:1~4 个动态数量,各配 1 条例句 + 中文翻译;短语本身不译

### 4.3 三层难度定义

| 层 | 句式 | 词汇 | 长度 | 数量 |
|---|---|---|---|---|
| L1 | 简单句(主谓宾/主系表,至多 1 并列) | 目标词外用词限 BNC 前 3000 | 5~10 词 | 3 |
| L2 | 可含从句(宾语/定语从句)、时间地点状语 | 引申义、常见搭配 | 10~18 词 | 3 |
| L3 | 复合句(多从句嵌套、非谓语、倒装、虚拟语气) | 书面语、习语化、生僻搭配 | 18~30 词 | 3 |

**软校验**:FRE(可读性)分数 L1 > L2 > L3,不达标重试一次(见 §6.4)。

### 4.4 水平参数映射(prompt 参数,非代码规则)

| 用户水平 | 例句词汇范围 | 基准复杂度 | 释义详细度 |
|---|---|---|---|
| 高考 | BNC 前 5000 + zk/gk 标签 | 三层基准下移,L1 更短更口语化 | 释义用词简单,每条附 1 个近义说明 |
| 四六级 | BNC 前 12000 + cet4/cet6 标签 | 中间基准 | 标准英文释义 |
| 专四专八 | BNC 前 30000 + gre/toefl/ielts 标签 | 基准上移,整体偏书面 | 精炼学术化释义 |

- 目标词本身不受限(正在学的词即使生僻也可以出现在例句中)
- **AI 英文释义纯英文,不带中文**;中文辅助仅来自 ECDICT 展示层(可选显示)

### 4.5 拼接规则(素材优先级)

`MDX(用户导入,优先)→ ECDICT(内置,兜底)→ AI(补缺)`

- 词典素材(音标/释义)永不覆盖
- **重新生成 = 按块**:重生成例句 / 重生成释义 / 全部,默认全选,用户可选
- 重新生成 = **覆盖即弃**,旧内容直接删除;操作前**二次确认**防误触

## 5. 素材来源架构(真值层)

> 门票:[讨论:词典真值层与素材来源](#11)

- **ECDICT 内置为基础层**:MIT 许可,可随 App 分发。构建期裁剪为精简 SQLite(去冗余字段,收高频词),目标 10~20MB。提供:音标(英式为主)、英文释义(简略)、中文释义、词性、柯林斯星级、牛津 3000、考试标签、BNC/当代双词频、动词变形
- **MDX 为增强层**:用户导入,素材优先于 ECDICT
- **AI 为生成层**:例句 + 精修释义,只补两者都没有的部分
- **已知缺口**:ECDICT 无专四/专八标签(只有 zk/gk/cet4/cet6/考研/gre/toefl/ielts)。专四专八用户按"无低级标签 + 词频排序"近似
- **等级的作用**:①生成参数(§4.4)②推荐排序(按考试标签 + 词频优先)③硬性过滤 = 用户可选项,默认关

### 5.1 包体积

- APK ≈ 40~60MB(含裁剪 ECDICT)
- 本地数据随词集增长:5000 词音频 ≈ 250MB(不入包,属设备数据)

## 6. 生成管线规格

> 门票:[讨论:生成管线与预算规格](#7)

### 6.1 触发与队列

- **单队列,双优先级**:即时生成(点开未生成词)最高优先;后台预生成在队列空闲时跑
- **预算只约束后台预生成;即时生成不受预算限制**
- 任务持久化存 SQLite(App 前台/短后台续跑);后台调度用 workmanager(Android WorkManager / iOS BGTaskScheduler;Web 实验性)

### 6.2 预算

- 每日阅读量 X(用户设置);预算倍数 M(默认 3,可配置)
- 后台预生成上限 = **M×X 词**;**按自然日重置**
- 达上限自动暂停,显示"已达今日预算";次日重置后变"继续下一批次"按钮

### 6.3 失败与重试

| 错误类型 | 策略 |
|---|---|
| 网络错误(超时/429) | 指数退避重试 3 次(1s/4s/16s) |
| 结构校验失败(JSON 解析不过) | 重试 2 次(属 prompt 质量问题,退避无用) |
| 仍失败 | 词标 `failed`,跳过继续,不阻塞队列 |

- 任务结束出**失败清单**;可在任务控制台**单点重试**
- 429 限流:渐进退避降速
- **超时**:connect/receive/send 各 20s(Web 端合计 40s);挂起按网络错误退避重试,不永久阻塞队列

### 6.4 质量校验

- JSON schema 校验(§4.1 结构)
- FRE 软校验:L1 > L2 > L3,不达标重试一次

### 6.5 并发

- 固定低并发池,默认 4;**用户可在设置中调整**
- 队列进度反馈:任务控制台(见 §9.4)

## 7. 导入管线规格

> 门票:[讨论:导入管线规格](#12)、[讨论:技术栈定案](#10)

### 7.1 统一流程(四种文本格式)

`选文件 → 自动探测解析 → 预览确认 → 入库`

1. **txt**:按行 + 分隔符探测(制表符/逗号/多空格),解析不出第二列降级为纯单词;BOM/空行/`#` 注释行跳过;GBK/UTF-8 编码探测(charset 包)
2. **markdown**:`#` 标题作词头,正文段落作释义,列表项作词条;无标题散落段落忽略;兜底为整份清洗后按行拆词
3. **excel/csv**:首行表头自适应(识别 word/单词/headword、meaning/释义、phonetic/音标、pos/词性),识别不到按"第一列词、第二列释义";**列映射用户可手动纠正**
4. **预览确认界面**:前 10 行解析结果表格 + 识别统计(识别词/识别释义/跳过行/可疑行)+ 列映射下拉纠正;确认后一次性入库
5. **MDX 不预览**(结构固定,直达)

### 7.2 MDX/MDD

- **变体范围**:仅 v1.2/2.0 + zlib + 无加密(dict_reader 直读);不支持的变体( LZO / v3.0 / 加密)导入时**明确报错**;RN 备选仅在"必需词典读不了且 pyglossary 预转换走不通"时重议
- **MDD 音频:懒提取**——导入时解析 `sound://` 引用建立索引;用户点发音时按需从 MDD 提取并缓存入库
- MDX 导入 = 整本进词集(默认);导入完成页给"立即筛选"入口(按标签/词频筛选)

### 7.3 词集语义

- **词集即中心,无独立素材库**;素材按词挂在词集内
- **词集去重**:同词集多次导入,已存在词跳过,只加新的
- **源文件导入即弃**(素材已提取入库,不保留文件引用)
- 导入进度:前台进度条(已解析 x/总计)→ 可切后台(复用任务队列基建)→ 可取消续导(已入库部分保留)
- **导入完成页 = 枢纽**:筛选入口 + "开始生成"入口 + 状态说明(未生成词如何学);**不自动触发全量生成**

## 8. 学习与复习

> 门票:[原型:单词阅读页形态](#9) + 早期决策(问题 2/4/5)

### 8.1 单词页:3 个预设视图模式(不做自定义布局)

| 模式 | 形态 | 场景 |
|---|---|---|
| **学习模式** | 分层阅读流:9 句按 L1/L2/L3 三个区块,顶部推荐路径引导(读完 L1 ✓),每句标注所属义项 | 新单词,按 L1→L2→L3 学义项 |
| **查阅模式** | 词典式:按词性/义项组织,释义下方挂例句,每句带 L 徽章,顶部层次进度条 | 快速查词 |
| **复习模式** | 逐句精读器:一次一句大字号居中,9 个圆点(按层着色)表进度,可展开全部 | 复习/自测 |

- 全局设置默认模式;单词页内右上角可即时切换(与展示配置同区)
- 3 模式共用内容契约 schema 数据,渲染层分模式实现
- 原型参考:分支 `prototype/word-page`(prototype/word-page.html,?variant=A/B/C)

### 8.2 展示配置

- 例句区 中英 / 仅英 / 仅中 三态切换,任意模式生效
- 复习场景:仅英 = 自测理解;仅中 = 练英语表达

### 8.3 页面共性(所有模式)

- 词头:单词 + 英/美音标 + 英音/美音发音按钮
- 音标来源:ECDICT(英式为主)/ MDX / AI 兜底;**美式尽量**
- 发音:按 TTS 方案(§10.3),本地缓存
- 复习标记:认识 / 不认识(进入轻量复习)
- 区块排布:词头 → 释义(按词性)→ 例句 → 常用短语

### 8.4 轻量复习(不做完整 SRS)

- 用户标记认识/不认识;App 按 1/3/7 天间隔把到期词推回复习
- 复习 = 复习模式(逐句精读器)+ 展示配置
- 复习状态属个人层(§3)
- **待定**:调度触发细节、复习批次构成(见 §13 未决项)

## 9. 局域网同步

> 门票:[讨论:局域网进度同步方案](#8)

**双通道架构:个人层自动同步 + 内容层主动拉取**

### 9.1 个人层(自动同步)

- **拓扑**:固定一台设备作 host(主力 Android 机,设置中指定);其余设备(第二台手机/Web)作 client。Web 端不能开 TCP 服务端(dart:io 在浏览器不可用)
- **发现**:Android client 用 mDNS(bonsoir)+ 手动 IP 兜底;Web 端扫码/手动输 IP
- **时机**:改动事件实时上报 host(标记认识/不认识、间隔变更即推);host 向已连接 client 每 5 分钟推增量(或变更时即时推)
- **协议**:按 word id 挂复习状态的变更日志,增量推送;冲突 **LWW(后改者胜)+ 设备逻辑序号**防时钟漂移
- **离线边界**:client 断线改动落本地待发队列,重连补发;离线期间两端各自工作,重连合并

### 9.2 内容层(词集拉取)

- 动机:局域网下手动导入导出文件不便
- **触发**:副设备"局域网 → 发现设备 → 选择词集 → 拉取"——一次性主动动作,不做内容层自动全量同步;文件导入导出保留并存
- **范围**:词集文本素材(例句/释义/音标,统一词条模型,走导入管线入库);**音频按需懒加载**(点发音向 host 请求单条音频并缓存);个人层不随词集走
- **版本**:本端已有旧版词集时,拉取以新版覆盖该词集内容层
- 复用同一 WebSocket 连接与设备发现通道

### 9.3 边界

- 一端无词时:显示"该词在另一台设备有进度,未在本机词集"占位 → 可即时生成或拉取词集
- 内容层版本不一致以各端本地为准,直到用户重新拉取/导入

### 10.3 TTS 发音方案

> 调研票 [5](#5) 决议

- **主方案**:批量预合成 + 本地缓存——edge-tts 免费生成固定 en-GB/en-US Neural voice 单词音频,打包/首次下载后纯本地播放,零运行时成本、完全离线;量大时 Azure TTS 兜底(有 SLA)
- **备方案**:设备端 flutter_tts 兜底自定义生词(Web 端离线与音频缓存不可保证)

## 11. 导出 / 导入词集

- **导出包 = 内容层**:AI 生成物 + 词典提取内容 + 单词集清单(完整可用素材);**个人层(复习状态/进度)不导出**
- 用途:个人学习自用(离线转移、备份);局域网拉取为另一通道(§9.2)
- 音频:随导出(内容层成员)或按需——以导出体积权衡,规格留实现选择
